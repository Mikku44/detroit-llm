# นโยบายความเป็นส่วนตัว Detroit LLM Gateway

**มีผลบังคับใช้: 4 กันยายน 2026** ผู้ควบคุมข้อมูล: **Detroit LLM / MIKKUCN** (chat.khain.app)

นโยบายฉบับนี้อธิบายว่าเราเก็บ ใช้ และปกป้องข้อมูลของท่านเมื่อใช้เว็บแชทและ OpenAI-compatible API ของ Detroit LLM Gateway อย่างไร

## 1. ข้อมูลที่เราเก็บ

- **บัญชีและการยืนยันตัวตน:** Google email, Google sub, YouTube Channel ID และสถานะ Membership (ผ่าน Google OAuth / YouTube Data API)
- **การชำระเงินแบบชำระตรง:** Stripe customer/subscription/payment-intent/invoice ID และประวัติธุรกรรม (เรา**ไม่เก็บ**บัตรเครดิต ตัวบัตรอยู่กับ Stripe)
- **API Key:** เก็บแบบ hash พร้อม prefix (`sk-dt-...`) วันที่สร้าง/ใช้ล่าสุด สถานะ (คีย์ดิบแสดงครั้งเดียวตอนสร้าง) ค่าลับบางอย่างอาจถูกเข้ารหัสที่ rest
- **การใช้งาน (Usage logs):** โมเดลที่ใช้ จำนวนโทเค็น prompt/completion/total วันเวลาที่ใช้ API key ที่ใช้
- **บทสนทนา (เฉพาะหน้าเว็บแชท — เนื้อหา API ไม่ถูกบันทึก):** ข้อความ ไฟล์แนบ (รูป/วิดีโอ/ข้อความ) reasoning/metadata การกดถูกใจ/ไม่ถูกใจ เนื้อหาข้อความของ tier เสียเงินมีการเข้ารหัส และแยกฐานข้อมูลจากข้อมูลบัญชี
- **ไฟล์/รูปที่สร้าง:** ไฟล์ที่อัปโหลดหรือรูปที่เจนเนอเรทอาจถูกเก็บบน R2 storage พร้อมบันทึกการใช้งานรายเดือน
- **เทคนิค:** Session token (JWT อายุ ~7 วัน) บันทึก rate limit/health และค่ากำหนดภาษา/consent ใน localStorage (`dlg_legal_lang`, consent flag)

## 2. วัตถุประสงค์การใช้

- ยืนยันสิทธิ์ (Membership/แผนชำระเงิน) ให้สิทธิ์ตาม tier
- บังคับโควต้าโทเค็น/รูปและ rate limit (นับ quota, anti-spam)
- ให้บริการแชท/API ดีบักและปรับปรุงประสิทธิภาพ
- จัดทำหน้า **Usage**/ประวัติธุรกรรมให้ท่านตรวจสอบ

## 3. Google / YouTube API Data

ข้อมูล **Google User Data / YouTube API** ใช้เพื่อยืนยันตัวตนและสถานะสมาชิกเท่านั้น ไม่แบ่งปันหรือส่งต่อให้บุคคลที่สาม การใช้งานสอดคล้องกับนโยบาย **Limited Use** ของ Google API Services

## 4. การส่งต่อให้ Third-party (Processors)

พรอมต์ของท่านจะถูกส่งไปประมวลผลยังผู้ให้บริการของโมเดลที่ท่านเลือกเท่านั้น ได้แก่ **DeepSeek**, **Alibaba Cloud DashScope (Qwen)**, **Z.AI (GLM)**, **Anthropic (Claude)**, **Google (Gemini)**, **xAI (Grok)** และ **OpenRouter** (fallback) รวมถึง **Stripe** (ชำระเงิน) และ **R2** (จัดเก็บไฟล์) ข้อมูลอยู่ภายใต้เงื่อนไขของผู้ให้บริการนั้นๆ เรา**ไม่ขาย**หรือแลกเปลี่ยนข้อมูลส่วนบุคคลและประวัติแชทเพื่อผลประโยชน์เชิงพาณิชย์โดยเด็ดขาด

## 5. ความปลอดภัย

ใช้มาตรการที่เหมาะสม: **hash คีย์**, **เข้ารหัส**ข้อมูลอ่อนไหวที่ rest, **JWT session**, แยกฐานข้อมูลบทสนทนา, จำกัดสิทธิ์ owner/admin และเรียกเก็บผ่าน Stripe/YouTube เท่านั้น (เราไม่เก็บข้อมูลการเงิน/บัตร)

## 6. การเก็บรักษาและการลบ

**ขอบเขตการจัดเก็บ — สำคัญ:**
- **ทุก tier — หน้าเว็บแชท:** บทสนทนาที่คุยผ่านหน้าเว็บแชทจะถูกบันทึกไว้ เพื่อให้ท่านกลับมาอ่าน/ใช้งานต่อได้
- **ทุก tier — API call:** การเรียกผ่าน API (`/v1/*` ด้วย API Key) จะบันทึกเฉพาะ **metadata การใช้งาน** (โมเดล จำนวนโทเค็น วันเวลา) เพื่อนับโควต้า/ทำบิลลิ่ง **ไม่มีการบันทึกเนื้อหาข้อความ**
- **tier เสียเงิน — การเข้ารหัส:** ประวัติแชทของ tier เสียเงินถูก**เข้ารหัสที่ rest** (คีย์เฉพาะต่อผู้ใช้+บทสนทนา) มีเพียง**เจ้าของบัญชีเท่านั้น**ที่อ่านกลับมาได้ แม้แต่ทีมงานก็อ่านเนื้อความไม่ได้

- ประวัติบทสนทนาหน้าเว็บ ท่านลบเองได้ในแอป
- ขอให้ลบประวัติ/ข้อมูลที่บันทึกได้ผ่านช่องทางสนับสนุน ([Discord](https://discord.gg/KuMVmcK3cC)) การสำรองข้อมูล (ถ้ามี) อยู่ภายใต้มาตรการเดียวกัน
- ยกเลิกเชื่อมต่อ/เลิกใช้ได้ตลอด สิทธิ์เข้าถึงยุติตามสถานะสมาชิก/การสมัครสมาชิก

## 7. สิทธิของท่าน คุกกี้ และอัปเดต

ท่านมีสิทธิขอ**เข้าถึง แก้ไข และขอลบ**ข้อมูลของท่านตามช่องทางข้างต้น เบราว์เซอร์เก็บเพียง session token และการตั้งค่าภาษา/consent ไม่มีโฆษณาติดตามของบุคคลที่สามบนหน้า Legal นโยบายนี้อาจปรับปรุงตามความเหมาะสม การเปลี่ยนแปลงสำคัญจะแจ้งผ่านช่องทางให้บริการ
