นโยบายความเป็นส่วนตัว (Privacy Policy)

นโยบายความเป็นส่วนตัวฉบับนี้อธิบายถึงวิธีการเก็บรวบรวม ใช้ และปกป้องข้อมูลส่วนบุคคลของท่าน เมื่อเข้าใช้งานบริการ AI Assistant (DeepSeek V4 Flash) สำหรับสมาชิก YouTube Membership

1. ข้อมูลที่เราทำการเก็บรวบรวม
เพื่อการให้บริการที่มีประสิทธิภาพและตรวจสอบสิทธิ์การใช้งาน เราอาจทำการเก็บรวบรวมข้อมูลดังต่อไปนี้:

ข้อมูลบัญชีผู้ใช้งาน: เช่น YouTube Channel ID, Discord User ID หรือ Email ที่ใช้ยืนยันสถานะการเป็นสมาชิก

ข้อมูลการใช้งาน (Usage Data): จำนวนข้อความที่ส่ง, เวลาที่ใช้งาน (Timestamp), ความยาวของ Prompt และประวัติการใช้อัตราโควต้า (Quota Consumption)

ข้อความในการสนทนา (Chat History/Logs): คำถามหรือข้อความ (Input Prompt) ที่ท่านส่งเข้าสู่ระบบเพื่อนำไปประมวลผลคำตอบ

2. วัตถุประสงค์ในการใช้ข้อมูล
เราใช้ข้อมูลของท่านเพื่อวัตถุประสงค์ดังต่อไปนี้เท่านั้น:

ยืนยันสิทธิ์: ตรวจสอบสถานะ YouTube Membership เพื่อให้สิทธิ์เข้าถึงบริการตามระดับชั้นสมาชิก

บริหารจัดการระบบ: ควบคุมปริมาณการใช้งานตามนโยบาย Fair Use Policy (เช่น การนับโควต้าประจำวัน และการทำ Anti-Spam)

ปรับปรุงการให้บริการ: ตรวจสอบข้อผิดพลาดของระบบ (Debugging) และพัฒนาประสิทธิภาพในการตอบสนองของ Bot/Web App

3. การส่งต่อและการประมวลผลข้อมูลกับบุคคลที่สาม (Third-Party Services)
DeepSeek API: ข้อความคำถาม (Prompt) ของท่านจะถูกส่งไปประมวลผลผ่าน DeepSeek API เพื่อสร้างคำตอบ ทั้งนี้ ข้อมูลจะถูกจัดการตามนโยบายความเป็นส่วนตัวและมาตรฐานความปลอดภัยของ DeepSeek

ไม่มีการขายข้อมูล: เราไม่มีนโยบายนำข้อมูลส่วนบุคคล หรือประวัติการแชทของท่านไปขาย หรือแลกเปลี่ยนเพื่อผลประโยชน์เชิงพาณิชย์แก่บุคคลที่สามโดยเด็ดขาด

4. การรักษาความปลอดภัยของข้อมูล (Data Security)
เราใช้มาตรการทางเทคนิคที่เหมาะสมเพื่อปกป้องข้อมูลส่วนบุคคลและ API Key จากการเข้าถึง การแก้ไข หรือการเปิดเผยโดยไม่ได้รับอนุญาต

ข้อมูลยืนยันตัวตนจะถูกนำมาใช้เพื่อเช็กสิทธิ์ระบบสมาชิกเท่านั้น และไม่มีการจัดเก็บข้อมูลทางการเงิน/บัตรเครดิตของท่าน (การชำระเงินดำเนินการผ่านระบบของ YouTube ทั้งหมด)

5. สิทธิของผู้ใช้งาน (User Rights)
ท่านสามารถยกเลิกการเชื่อมต่อบัญชี หรือยกเลิกการใช้งานได้ตลอดเวลา ซึ่งสิทธิ์ในการเข้าถึงระบบจะยุติลงพร้อมกับสถานะสมาชิก YouTube

ท่านสามารถร้องขอให้ลบประวัติการสนทนา หรือข้อมูลที่บันทึกไว้ในระบบบริการของเราได้ โดยติดต่อผ่านช่องทางสนับสนุนของผู้ให้บริการ

นโยบายความเป็นส่วนตัวนี้อาจมีการปรับปรุงตามความเหมาะสม หากมีการเปลี่ยนแปลงสำคัญจะแจ้งให้ทราบผ่านช่องทางให้บริการ
