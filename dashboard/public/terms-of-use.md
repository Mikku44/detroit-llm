# ข้อกำหนดการใช้งาน Detroit LLM Gateway

**มีผลบังคับใช้: 4 กันยายน 2026**

Detroit LLM Gateway (**"บริการ"**) ให้บริการเว็บแชทและ OpenAI-compatible API (`/v1/chat/completions`, `/v1/models`) ผ่านโมเดลหลายตัวในที่เดียว ดำเนินการโดย **MIKKUCN** (chat.khain.app) การสมัครและใช้งานถือว่าท่านยอมรับข้อกำหนดฉบับนี้

## 1. บริการและโมเดล

บริการให้ท่านสลับโมเดลได้ตามงาน เช่น **deepseek-v4-pro / deepseek-v4-flash**, **qwen3.7-flash / qwen3.8-flash** (Alibaba DashScope), **glm-5.3 / glm-5.3-flash / glm-4.5-air / glm-4.7-flashx** (Z.AI), **gemini-2.5-flash**, โมเดลกลุ่ม **Claude Extra** (Anthropic) และโมเดลสร้างภาพ (z-image-turbo, glm-image, grok-imagine-image) รายชื่อจริงดูได้ที่ `GET /v1/models` หรือหน้า **Models** โมเดลและความพร้อมอาจเปลี่ยนโดยไม่ต้องแจ้งล่วงหน้า

## 2. บัญชีและสิทธิ์เข้าถึง

- เข้าสู่ระบบด้วย **Google (OAuth)** ระบบยืนยันสถานะ **YouTube Membership** อัตโนมัติ หรือสมัครแพ็กเกจแบบชำระเงินผ่าน **Stripe**
- ท่านต้องรักษา **Session** และ **API Key** (`sk-dt-...`) เป็นความลับ ห้ามแชร์หรือฝังในโค้ดฝั่ง client ที่เปิดเผยต่อสาธารณะ ความเสียหายจากการรั่วไหลของคีย์เป็นความรับผิดชอบของท่าน (เพิกถอนและออกคีย์ใหม่ได้ที่หน้า **Keys**)
- แผน **Free** ใช้งานได้โดยไม่ต้องชำระเงินภายใต้โควต้า Free tier

## 3. แผน โควต้า และข้อจำกัดทางเทคนิค

- โควต้าเป็นแบบโทเค็น**รายวัน/รายสัปดาห์/รายเดือน** (input+output รวมกัน) ตาม tier ของท่าน เช่น **Free 100,000 โทเค็น/สัปดาห์ และ 435,000 โทเค็น/เดือน** (โควต้ารายวัน = รายสัปดาห์ ÷ 7) แผนชำระเงิน (**Nomad / Dreamer / Entrepreneur / Angel** และแพ็กเกจ **Extra Claude**) มีโควต้าสูงกว่าตามที่แสดงในหน้า **Upgrade/Usage**
- **โมเดล Free tier:** กลุ่ม `flash` (เช่น deepseek-v4-flash, qwen3.7-flash, qwen3.8-flash, gemini-2.5-flash) บวก glm-4.5-air / glm-4.7-flashx ยกเว้น **deepseek-v4-flash-vision-exp, glm-5.3 และ glm-5.3-flash** ที่ต้องเป็นสมาชิก/แผนชำระเงิน โมเดล **Claude Extra** ต้องใช้แพ็กเกจ Extra Claude โดยตรงและมีโควต้า Input/Output แยกบวกจำกัดงานพร้อมกัน 2 งาน
- โควต้ารูปภาพรายเดือนแยกต่างหาก (เช่น **Free 2 ภาพ/เดือน**) ตาม tier
- จำกัดอัตรา **60 คำขอ/นาที** และขนาดคำขอสูงสุด **~1MB** การใช้เกินจะถูกปฏิเสธด้วย **403/429** ชั่วคราว ไม่ถือว่าบริการขัดข้อง

## 4. การใช้งานที่ยอมรับได้

- **อนุญาต**ให้ใช้ API, Script และระบบอัตโนมัติผ่าน API Key ของท่านเองภายในโควต้าและ rate limit (ต่างจากฉบับเดิมที่ห้ามอัตโนมัติทั้งหมด)
- **ห้าม:**
  - เนื้อหาผิดกฎหมาย ละเมิดลิขสิทธิ์ Hate Speech คุกคามผู้อื่น สื่อลามก ความรุนแรงสุดโต่ง
  - การทำ Prompt Injection / Jailbreak / เจาะระบบ
  - การขโมย/เดาคีย์ผู้อื่น การเลี่ยงโควต้า/rate limit การสแปมหรือยิงคำขอรัว และการนำบริการไปโจมตีระบบอื่น
- ผลลัพธ์ โค้ด และเนื้อหาที่ AI สร้าง ท่านนำไปใช้เชิงพาณิชย์ได้โดยไม่มีข้อจำกัดจากเรา (สิทธิตามกฎหมายทรัพย์สินทางปัญญาของบุคคลที่สามยังคงมีผล ท่านต้องรับรองเองว่ามีสิทธิ์ใช้)

## 5. ข้อจำกัดความรับผิด (Disclaimer)

คำตอบสร้างโดยโมเดลของ Third-party หลายเจ้า **ไม่รับประกันความถูกต้อง 100%** โปรด **Fact-check** ก่อนใช้กับเรื่องแพทย์ กฎหมาย การเงิน หรือธุรกรรมสำคัญ เราไม่รับผิดต่อความเสียหายจากการนำคำตอบไปใช้ต่อทุกกรณี

## 6. การชำระเงินและการคืนเงิน

- ค่าสมาชิก YouTube ชำระผ่านระบบของ **YouTube** ตามเงื่อนไขของ YouTube
- แพ็กเกจชำระตรงชำระผ่าน **Stripe** ข้อมูลบัตรอยู่กับ Stripe เราไม่เก็บบัตรของท่าน
- หากถูกระงับเพราะละเมิดข้อกำหนด จะไม่มีการคืนเงิน การยกเลิกหรือเปลี่ยนแผนมีผลตามรอบบิลของ Stripe/YouTube

## 7. การระงับและสิ้นสุดสิทธิ์

สิทธิ์เข้าถึงผูกกับสถานะสมาชิก/การสมัครสมาชิก หากสถานะสิ้นสุดหรือพบการละเมิด (เช่น สแปม ใช้ผิดทาง แชร์คีย์ในทางที่ก่อความเสียหาย) เราอาจจำกัดหรือระงับการใช้งานทันทีโดยไม่ต้องแจ้งล่วงหน้า
